# Amrinder Sahota website sitemap

This repository hosts only the public XML sitemap for https://www.amrindersahota.ca/.
The author website remains on Google Sites.

The sitemap contains 15 verified canonical page URLs. Dates are omitted unless a significant update date is known.
Publish from the main branch root using GitHub Pages. No build dependencies, custom domain, forms, analytics or secrets are required.

When an author-website page is added or retired, verify its final public URL and update sitemap.xml. Keep Google Search Console ownership-verification files in place if present.
